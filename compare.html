Backtest Comparison v0.1

Compare two to four runs side by side, for example an EA before and after a change. The tool shows what moved, flags trade-offs hidden behind a better headline number, and tests whether a per-trade difference is more than noise. Files are processed in your browser and never uploaded.

Use the same kind of file for every run: all closed-trade / deals CSVs, or all Strategy Tester graph CSVs. The first run is the baseline. Trade lists enable the noise test, so prefer them.
