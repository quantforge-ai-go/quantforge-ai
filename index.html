Tools

Start with your own backtest data.

All tools run entirely in your browser. Your files are never uploaded.

Backtest Analyzer

Import a closed-trade or deals CSV, or a Strategy Tester graph export. Get outlier dependence, tail risk, cost drag, floating drawdown, a behaviour breakdown and a downloadable report.

Optimization Check

Import MT5 optimization results. Detect isolated peaks, parameter sensitivity, thin trade counts and back-to-forward decay before trusting the best pass.

EA Log Reader

Import an Experts/Journal or terminal log. Find failed orders, retry storms, runtime errors, stop-outs, EA restarts and log flooding, each with what to check in the code.

MQL5 Code Review

Paste an Expert Advisor and get a risk-control checklist: stop loss, lot and price normalisation, order-result handling, retry loops, exposure caps and a drawdown kill-switch.

Test Plan Generator

Turn an EA's profile and known problems into a test plan: walk-forward windows with real dates, robustness matrix, acceptance criteria and an ordered run sheet.
